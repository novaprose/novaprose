The editor is and will stay **free and open source (MIT)**. You can self-host everything you see
in this documentation today.

**NovaProse Cloud** is the paid hosted platform we are building on top of it, for teams that don't
want to run the server-side pieces themselves:

| Service                 | What it gives you                                                                   |
| ----------------------- | ----------------------------------------------------------------------------------- |
| CDN with API keys       | load the editor with one line; keys are bound to your domains                       |
| Fair usage billing      | only loads from your approved domains count, with protection against inflated loads |
| Real-time collaboration | multi-user editing, presence, comments, revision history                            |
| File and image storage  | uploads without your own storage, or adapters for your S3                           |
| Conversion              | import Word documents, export to PDF and Word                                       |
| AI                      | writing assistance with your choice of model                                        |
| REST API and webhooks   | read and write documents from your server, get notified on changes                  |

Every cloud service will also be available as a self-hosted container.

## Status

The cloud is planned after the core editor and real-time collaboration are complete. If you want
early access, or want to tell us what you need, email **hello@novaprose.com**.
