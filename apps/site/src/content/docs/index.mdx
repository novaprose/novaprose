<CardGrid stagger>
  <Card title="Secure by default" icon="approve-check">
    Link and image URLs are checked on input and on output, unsafe markup is dropped, and the UI
    never injects your users' content with `innerHTML`.
  </Card>
  <Card title="Deterministic HTML" icon="document">
    `getHTML()` returns the same string in every browser, so diffs, snapshots and server-side
    comparisons stay stable.
  </Card>
  <Card title="Native framework packages" icon="puzzle">
    React hooks, Vue `v-model`, Angular Reactive Forms, and a `<novaprose-editor>` element that
    works as a real form field.
  </Card>
  <Card title="Accessible" icon="star">
    ARIA roles, full keyboard navigation (Alt+F10, Alt+F9, Esc), visible focus and screen-reader
    labels everywhere.
  </Card>
  <Card title="Collaboration built in" icon="random">
    Real-time co-editing with live cursors, comments, @mentions, version history and suggested
    edits — included, with an open-source sync server you can host.
  </Card>
  <Card title="Small and fast" icon="rocket">
    About 130 KB gzip with ProseMirror and tables. Optional plugins load lazily. Moving an
    existing editor over? See the [migration guides](/migrate/).
  </Card>
</CardGrid>
