Mentions

The mentions plugin lets people type @ and pick a colleague from a list. It works in the document text and in comments.

In the text a mention is one unit (Backspace removes it whole) and is saved as:

getMentions(editor) returns everyone mentioned in the document, once each — handy for sending notifications when the document is saved. User ids may contain letters, digits and _ . @ : + -; anything else, and any markup in names, is rejected or shown as plain text.

Mentions in comments

Section titled “Mentions in comments”

With both comments and mentions enabled, @ in a comment opens the same list. The comment stores who was mentioned, and onMention lets you notify them:
