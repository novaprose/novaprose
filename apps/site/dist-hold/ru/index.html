Вопросы

Редактор правда бесплатный?

Да. Редактор, все плагины и сервер совместной работы открыты под лицензией MIT. Их можно использовать в коммерческих продуктах без оплаты и разрешений.

Зачем тогда облако?

Для совместной работы нужен сервер. Наш можно запустить у себя через Docker, а облако — для команд, которые не хотят его обслуживать, масштабировать и бэкапить.

Сколько будет стоить облако?

Мы опубликуем цены до открытия. Участники листа ожидания узнают первыми, а первые клиенты получат скидку.

Нужен ли ключ или аккаунт, чтобы пользоваться редактором?

Нет. Установите из npm или подключите с публичного CDN — без регистрации, ключей и ограничений.

Можно ли перенести готовую интеграцию другого редактора?

Часто да. Есть слой совместимости для настроек tinymce.init(): готовая интеграция сначала заработает как есть, а на нативный API можно перейти позже.
