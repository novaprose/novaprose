Questions

Is the editor really free?

Yes. The editor, every plugin and the collaboration server are open source under the MIT license. You can use them in commercial products without paying or asking.

Why would I need Cloud then?

Collaboration needs a server. You can run ours yourself with Docker; Cloud is for teams that would rather not operate, scale and back it up.

How much will Cloud cost?

We will publish prices before Cloud opens. Waitlist members hear first, and founding members get a discount.

Do you need an API key or account to use the editor?

No. Install it from npm or load it from a public CDN — no sign-up, no keys, no usage limits.

Can I use NovaProse with my existing editor setup?

Often yes. There is a compatibility layer for tinymce.init() configurations, so an existing setup can run first and move to the native API later.

Start building in minutes

Install from npm, or add one script tag. No account needed.
